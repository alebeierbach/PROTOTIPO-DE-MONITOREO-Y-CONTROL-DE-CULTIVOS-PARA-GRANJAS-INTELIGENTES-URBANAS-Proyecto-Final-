\chapter*{Resumo}
\addcontentsline{toc}{chapter}{Resumo}

O presente Projeto Integrador descreve o projeto, a construção e o comissionamento de um protótipo de fazenda urbana vertical inteligente. O objetivo do sistema é automatizar o cultivo em ambientes internos, monitorando e controlando de forma autônoma as principais variáveis ambientais: temperatura, umidade do ar, intensidade da luz e umidade do solo. Para o seu desenvolvimento, foi construída uma estrutura física de vários níveis adaptada para o cultivo tradicional no solo. O equipamento conta com uma unidade central de processamento encarregada de receber os dados dos sensores e ativar os diferentes equipamentos de controle. Estes incluem painéis de iluminação artificial, uma rede de irrigação localizada com recuperação de água e um sistema de ventilação automática. A montagem geral foi concluída com peças mecânicas fabricadas sob medida para garantir o suporte adequado de todos os elementos. Na parte de software, foi programada uma lógica de controle que permite manter o clima e a irrigação dentro dos parâmetros necessários para as plantas em todos os momentos. Além disso, o equipamento possui conexão à internet para enviar os dados para a nuvem, o que torna possível monitorar o estado do cultivo à distância e em tempo real, aplicando o conceito de Internet das Coisas (IoT).
